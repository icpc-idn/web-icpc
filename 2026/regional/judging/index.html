Judging System

Last modified: 28 Sep 2026, 01:26 WIB

The 2026 ICPC Asia Jakarta Regional Contest use DOMjudge (version TBA) as the contest platform.

Contest system team manual will be released soon.

Programming Languages

The supported programming languages for INC 2026 are:

  • C
  • C++
  • Java
  • Python 3
  • Kotlin

Note that a Python solution can be much slower compared to the other two programming languages, thus, we do not guarantee all the problems can be solved with the time-limit constraint with Python even though the same algorithm is being used. Nevertheless, you may use Python as you see fit.

The grader machines are preconfigured with these compilers:

  • C (TBA)
  • C++ (TBA)
  • Java (TBA)
  • Python 3 (TBA)
  • Kotlin (TBA)
